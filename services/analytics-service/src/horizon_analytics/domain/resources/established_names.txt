# Устоявшиеся имена технологий, начинающиеся со степенного прилагательного.
#
# Зачем файл существует
# ─────────────────────
# Правило границы отвергает имя, если первое или последнее слово — служебная лексика научного
# текста. Для оценочных прилагательных («novel», «existing», «prior») правило верно: они
# характеризуют, а не называют. Для степенных («high», «low», «large», «small») оно верно ровно до
# тех пор, пока прилагательное не входит в устоявшееся имя, — и тогда продукт теряет настоящую
# технологию молча.
#
# Потери названы и измерены (`docs/01-analysis/30-boundary-filter-findings.md` §5): `large language
# model`, `small modular reactor`, `high bandwidth memory`. Первое из них README называет среди
# двадцати имён, которые старое правило теряет.
#
# Почему список, а не правило
# ───────────────────────────
# Отличить устоявшееся имя от случайного сочетания нечем, кроме внешнего знания: «large language
# model» — имя, «large transaction batches» — обрывок, и обе фразы устроены одинаково. Попытки
# отличать по длине имени или по частоте — величины, подобранные под известные примеры; в записке о
# границах такие описаны трижды и все откачены.
#
# Размер списка измерен, а не предположен. На эталонном корпусе среди фраз, начинающихся со
# степенного прилагательного и встречающихся не реже трёх раз, настоящих имён оказалось два из
# тридцати трёх. Список такого размера ведётся руками — как и перекрёстный словарь направлений.
#
# Формат: одно имя в строке, в исходной форме. Стемминг применяется при загрузке, поэтому
# «models» и «model» дают одну запись.

# ── по замеру эталонного корпуса ──────────────────────────────────────────────
large language model
small modular reactor

# ── общеизвестные имена, отсутствующие в эталонном корпусе ─────────────────────
# Добавлены по знанию предметной области, а не по подгонке под замер: продукт предназначен не
# только для этого корпуса, и потерять HBM на реальных данных дороже, чем содержать здесь строку.
high bandwidth memory
high availability cluster
high performance computing
high frequency trading
low earth orbit
low power wide area network
solid state drive
